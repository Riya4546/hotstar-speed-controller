# Hotstar Speed Controller

A lightweight Chrome extension that adds playback speed controls to Disney+ Hotstar.

This extension allows users to watch content at different playback speeds directly from a simple popup interface.

---

# Features

* Change playback speed instantly
* Supports:

  * 1x
  * 1.25x
  * 1.5x
  * 2x
* Lightweight and fast
* Simple user interface
* Works directly inside Hotstar player
* Built using Chrome Extension Manifest V3

# Installation

## Method 1 — Download ZIP from GitHub

### Step 1

Download the repository ZIP file from GitHub.

### Step 2

Extract the ZIP file.

### Step 3

Open Google Chrome.

### Step 4

Go to:

```text
chrome://extensions
```

### Step 5

Enable:

```text
Developer mode
```

(top-right corner)

### Step 6

Click:

```text
Load unpacked
```

### Step 7

Select the extracted project folder.

---



# Usage

1. Open Disney+ Hotstar
2. Play any movie or show
3. Click the extension icon in Chrome toolbar
4. Select your preferred playback speed:

   * 1x
   * 1.25x
   * 1.5x
   * 2x

Playback speed updates instantly.
